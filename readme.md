# 📦 Sistema de Controle de Estoque

Sistema de controle de estoque desenvolvido em Python para praticar
Programação Orientada a Objetos (POO).

## Funcionalidades

- Cadastrar produtos
- Listar produtos
- Buscar produtos
- Adicionar quantidade ao estoque
- Retirar quantidade do estoque
- Editar produtos
- Excluir produtos

## Tecnologias

- Python
- Programação Orientada a Objetos (POO)

## Como executar

Execute o arquivo principal:

python main.py

## Objetivo

Projeto desenvolvido para praticar meus conhecimentos em Python.
